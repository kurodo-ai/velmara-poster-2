A vintage-style travel poster for Velmara, an invented cliff city above a dusk lagoon, drawn entirely in code with Pillow: a spiral lighthouse tower, a low amber sun, banded water and the city's name set in serif capitals. The generator lives in src/make_image.py; main.py hands the finished poster in.

## Run it

```sh
python3 main.py
```
